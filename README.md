# 📄 쉬운말 번역기 (Easy Notice)

> **어려운 안내문을 찍으면 "내가 할 일"로 바꿔주는 생성형 AI 서비스**

동양미래대학교 컴퓨터소프트웨어공학과 **인공지능프로젝트** 개별 프로젝트 (2026-2학기) · Vercel 배포 중

## 💡 프로젝트 개요

고지서, 임대차계약서, 병원·학교 안내문처럼 **전문용어와 한자어가 많은 생활 문서**를 사진 한 장으로 이해하도록 돕는 웹 서비스입니다.

문서를 찍으면 AI가 **① 쉬운 말로 요약**하고, **② 기한·금액 같은 핵심 정보를 정리**하고, **③ 해야 할 일을 체크리스트로** 만들어 줍니다.

**왜 필요한가?** 문서를 이해하지 못하면 납부 기한을 놓쳐 가산금을 내거나, 계약서의 불리한 조항을 모르고 서명하는 등 실제 손해로 이어집니다. 기존 번역기나 챗봇은 요약만 해 줄 뿐 **"언제까지 무엇을 해야 하는지"**는 알려주지 않습니다.

**예상 사용자:** 어르신, 외국인 주민·유학생, 사회초년생·대학생, 부모님 문서를 대신 봐 드리는 보호자

> **예시 —** 과태료 고지서를 찍으면
> "주정차 위반으로 **과태료 4만 원**이 나왔어요. **11월 30일까지** 내면 **3만 2천 원**만 내면 돼요."
> ✅ 11월 30일까지 32,000원 내기 · ⚠️ 기한이 지나면 할인이 없어지고 가산금이 붙을 수 있어요

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| ⭐ **문서 인식·쉬운말 요약** | 문서 종류(고지서·계약서·안내문·병원)를 판별하고, 설명 수준(아주 쉽게/보통)에 맞춰 3줄 요약 |
| ⭐ **핵심 정보·할 일 체크리스트** | 기한(D-day)·금액·내는 곳·문의처, 할 일 체크리스트, 주의할 점(불리한 조항·미납 불이익) |
| ⭐ **어려운 말 풀이** | 문서 속 어려운 용어의 뜻·예시와 문서에서 쓰인 문장, 원문 전체 보기(용어 하이라이트) |
| 문서 기반 질문·답변 | 문서 내용만 근거로 답하고 근거 원문 문장을 함께 표시, 없으면 문의처 안내 |
| 다국어 번역 | 영어·중국어·베트남어, 행정 용어는 괄호에 한국어 원어 병기 |
| 접근성 | 소리로 듣기(기기 내장 음성), 큰 글씨 모드, 쉬운 말 UI 문구 |

## 🏗 시스템 구조

![시스템 구조](docs/architecture.png)

```
고지서 사진 → GPT 1차(Vision: 글자 읽기·정보 추출) → 개인정보 마스킹 → 프롬프트 생성 → GPT 2차 → 검증 → 쉬운 안내문
             └──────────── /api/extract ────────────┘   └────────────── /api/explain ──────────────┘
질문하기: /api/chat (마스킹된 텍스트 + 질문)   번역: /api/translate (쉬운 안내문 → 영·중·베)
```

GPT 호출을 **"읽기"와 "쉽게 쓰기" 2단계**로 나눴습니다.

- **GPT 1차 (Vision):** 문서 이미지에서 글자를 그대로 옮기고, 문서 종류·기한·금액 등을 JSON으로 정리합니다.
- **서버:** 주민등록번호·전화번호·계좌번호·이름 등을 정규식으로 `[개인정보]`로 가린 뒤, 문서 종류와 설명 수준에 맞는 프롬프트를 만듭니다.
- **GPT 2차:** 마스킹된 텍스트만 받아 3줄 요약, 할 일, 주의 알림, 용어 풀이를 만듭니다.
- **검증:** zod로 형식을 확인(실패 시 1회 재요청)하고, 1차에서 뽑은 날짜·금액과 2차 결과를 코드로 비교해 다르면 원문 값을 우선하고 경고를 띄웁니다. 원문에 없는 용어, 원문에 없는 질문 근거 문장은 걸러냅니다.

**사진은 서버에 저장하지 않고**, 이미지는 1차 호출에만 쓰입니다. 쉬운 안내문 생성·질문·번역에는 마스킹된 텍스트만 전송됩니다. 모든 OpenAI 호출은 `store: false`로 보내고, 서버 로그에는 문서 내용 없이 에러 코드만 남깁니다.

## 🚀 실행 방법

**요구 사항:** Node.js 20+, OpenAI API 키

```bash
git clone https://github.com/chiyyy/easy-notice.git
cd easy-notice
npm install
```

`.env.example`을 복사해 `.env.local` 파일 생성:

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
MOCK_LLM=false   # true면 API 키 없이 예시 결과(과태료 고지서)로 화면을 확인할 수 있어요
```

```bash
npm run dev                 # http://localhost:3000
npm run dev -- -H 0.0.0.0   # 같은 와이파이의 휴대폰에서 접속
npm run lint && npx tsc --noEmit
npm test                    # 단위 테스트 (마스킹·검증·D-day·프롬프트 등)
```

**배포 (Vercel):** GitHub 저장소를 Import하고 환경 변수 `OPENAI_API_KEY`, `OPENAI_MODEL`, `MOCK_LLM=false`를 설정합니다. 이후 `main`에 머지하면 자동으로 다시 배포됩니다.
